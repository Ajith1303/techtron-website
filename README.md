# TechTron - Information Technology Association Website

Official website of **TechTron**, the Information Technology Association of Kings Engineering College. Built with modern web technologies for a fast, responsive, and engaging experience.

## 🚀 Tech Stack

- **React 18** - UI library
- **Vite 5** - Build tool & dev server
- **Tailwind CSS 3** - Utility-first styling
- **Framer Motion** - Animations & transitions
- **React Router** - Client-side routing
- **Swiper** - Carousels & sliders
- **React Icons** - Icon library

## 📁 Project Structure

```
├── public/          # Static assets (images, gallery, member photos)
├── src/
│   ├── assets/      # Imported assets
│   ├── components/  # Reusable UI components
│   ├── data/        # Site data & content
│   ├── hooks/       # Custom React hooks
│   ├── motion/      # Animation variants
│   ├── pages/       # Page components
│   ├── styles/      # Global styles
│   ├── App.jsx      # App root & routing
│   └── main.jsx     # Entry point
├── index.html
├── package.json
└── vite.config.js
```

## 🛠️ Getting Started

### Prerequisites

- **Node.js** (v18 or later)
- **npm** (comes with Node.js)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Ajith1303/techtron-website.git

# 2. Navigate to the project directory
cd techtron-website

# 3. Install dependencies
npm install
```

### Development

```bash
npm run dev
```

Runs the app in development mode. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### Production Build

```bash
npm run build
```

Builds the app for production to the `dist/` folder. It bundles React in production mode and optimizes the build for the best performance.

### Preview Production Build

```bash
npm run preview
```
